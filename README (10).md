# Joyrinah Schools Management System — Portfolio Demo

A polished, interactive school management platform demonstration prepared by Malik Technologies.

## Demo experience
This portfolio build uses fictional but realistic Kenyan-style institutional data so a prospective client can explore the platform as if it were an active system. It includes a 326-student demo dataset, 42 staff records, 84 library resources, admissions, payments, attendance, results, LMS, finance, HR, analytics, alumni and administration records.

Demo actions are interactive: adding a student, posting a sample payment, and recording attendance update the in-browser demo state and recent activity feed. No external database or real school data is connected.

## Portfolio deployment
The project is structured for a nested portfolio route:

`/build/joyrinah-schools/`

It includes Netlify configuration, an SVG favicon, security headers, responsive styling and SEO metadata.

## Production phase
This is a client-facing concept/demo. Once contracted, the demo state can be replaced with a production backend, PostgreSQL, server-side authentication and authorization, audit logging, backups, M-Pesa/bank integrations, SMS/email, biometric/QR attendance integrations, document storage and production reporting.
